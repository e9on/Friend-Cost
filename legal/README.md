## 이 문서들의 위치

`mdfiles/` 가 아니라 여기에 두는 이유는, 저 폴더의 문서들이 **서비스를 어떻게
만들지**를 정하는 명세이기 때문이다. 이 둘은 **이용자에게 보여줄 글**이라
성격이 다르고, 최종적으로는 웹 페이지가 되어 `VITE_TERMS_URL` 과
`VITE_PRIVACY_URL` 에 연결된다.

## 공개하기 전에

1. **변호사 검토를 받는다.** 사실관계(보관 기간, 제3자 제공 범위, 저장 항목)는
   코드에서 확인해 적었지만 조항의 법적 유효성은 확인하지 않았다.
2. `{{ }}` 자리를 채운다. 운영자명, 연락처, 개인정보 보호책임자, 시행일,
   클라우드 사업자.
3. 웹 페이지로 만들고 프론트 환경변수에 연결한다.

## 특히 검토가 필요한 곳

| 위치 | 왜 |
| --- | --- |
| 약관 5조 | 대화 상대방의 개인정보 책임을 이용자에게 두는 구조다. 약관만으로 운영자 책임이 면제되지 않을 수 있다 |
| 약관 8조 3항 | 책임 배제 조항은 「약관규제법」 제7조로 무효가 될 수 있다 |
| 처리방침 3장 | 동의하지 않은 제3자(대화 상대방)의 정보를 처리하는 적법 근거 |
| 처리방침 6장 | 「개인정보 보호법」 제28조의8 국외 이전 요건 |

## 사실관계는 테스트가 지킨다

`backend/tests/test_docs_consistency.py` 의 `TestLegalDrafts` 가 이 문서들을
코드·설정과 대조한다.

- 보관 기간이 `FC_TTL_SECONDS` 와 같은가
- 제3자로 적힌 사업자가 배포할 `FC_LLM_PROVIDER` 와 같은가
- "이미지는 외부로 나가지 않는다"가 `FC_OCR_ENGINE` 과 맞는가
- 문서가 스스로 "법률 검토 전"임을 밝히는가

**틀린 고지는 없는 것보다 나쁘다.** `google_vision` 으로 바꾸면 이미지가
외부로 나가므로 처리방침의 서술이 거짓이 된다. 그때 테스트가 먼저 깨진다.
