**계정을 만들지 않는다.** 이름, 전화번호, 이메일, 로그인 정보를 받지 않는다.

**대화 상대의 이름·닉네임은 인식 즉시 폐기한다.** 캡처의 말풍선 위에는 상대의 닉네임이 붙어 있다. 서비스는 이를 좌표로 찾아내 분석 대상에서 제외하며, 분석·저장·외부 전송 어디에도 사용하지 않는다.

**캡처에 남은 그 밖의 정보는 이용자가 가려야 한다.** 전화번호, 주소, 계좌번호, 사진처럼 대화 본문에 섞인 것은 서비스가 자동으로 구분할 수 없다. 업로드 화면에서 이를 안내한다.

**IP 주소는 저장하지 않는다.** 이용 횟수 제한을 위해 메모리에서만 세며, 하루가 지나거나 서버가 재시작되면 사라진다.

## 2. 처리 목적

1. 업로드한 대화의 관계 지표 산출과 결과 제공
2. 과도한 이용 방지(IP 기준 횟수 제한)
3. 오류 대응과 서비스 안정성 확인

**다른 목적으로 쓰지 않는다.** 광고, 프로파일링, 인공지능 모델 학습에 사용하지 않는다.

## 3. 대화 상대방의 개인정보

이 서비스의 가장 중요한 부분이므로 따로 적는다.

이용자가 올리는 캡처에는 **대화 상대방이 쓴 메시지**가 들어 있다. 상대방은 이 서비스에 동의한 적이 없다.

그래서 다음과 같이 처리한다.

1. **이용자는 본인이 참여한 대화만 올려야 한다.** 업로드 전에 이를 확인받는다.
2. 대화 내용은 **분석에만 쓰고 5분 뒤 삭제**한다. 이용자가 즉시 삭제를 요청할 수도 있다.
3. **대화 원문을 화면으로 되돌려 보내지 않는다.** 분석 결과에는 요약된 서술만 실린다. 원문 조각이 섞이지 않도록 서버가 한 번 더 검사해 걸러낸다.
4. **대화 원문을 기록에 남기지 않는다.** 운영 기록에는 메시지 개수, 이미지 장수 같은 숫자만 남는다.
5. 대화 상대방이 자신의 정보 처리를 확인하고 싶으면 e9on980@gmail.com로 요청할 수 있다. 다만 계정과 식별자를 저장하지 않으므로, **5분이 지난 자료는 확인할 방법이 없다.**

> **검토 필요.** 이 구성은 "이용자가 정당한 권한으로 올린다"는 전제 위에 있다. 「개인정보 보호법」상 운영자의 지위, 상대방의 열람·삭제 요구권, 동의 없는 수집의 적법 근거는 법률 검토가 필요하다.

## 14. 자동 수집 장치의 설치·운영 및 거부

이 서비스는 **쿠키를 사용하지 않는다.** 광고 식별자, 분석 도구(Google Analytics 등), 추적 픽셀도 두지 않는다.

브라우저의 `localStorage` 에 다음 한 가지만 저장한다.

| 이름 | 저장하는 값 | 목적 | 보관 |
| --- | --- | --- | --- |
| `fc.consent.v1` | 최초 동의 여부(`true`) | 접속할 때마다 동의를 다시 묻지 않기 위해 | 이용자가 지울 때까지 |

**개인을 식별하는 값이 아니다.** 이용자 번호도, 접속 이력도, 분석 결과도 담기지 않는다. 이 값은 이용자의 기기 안에만 있으며 서버로 전송되지 않는다.

**서비스 이용 흐름을 자체적으로 집계한다.** 화면에서 어느 단계까지 진행했는지를 서버에 남긴다(예: 화면 진입, 동의 완료, 이미지 선택, 결과 확인). 어디에서 이용을 멈추는지 파악해 서비스를 고치기 위한 것이다.

| | |
| --- | --- |
| 남기는 것 | 단계 이름과 발생 횟수 |
| 남기지 않는 것 | 이용자 식별자, 세션 식별자, IP 주소, 대화 내용 |
| 외부 전송 | 없음. 운영자의 서버에만 기록한다 |

**개인을 이어붙이지 않는다.** 누가 어느 단계까지 갔는지는 알 수 없고, 단계별 합계만 남는다. 구글 애널리틱스 같은 외부 분석 도구를 쓰지 않는 이유도 같다. 그런 도구는 이용자를 식별하고 데이터를 국외로 보낸다.

**거부 방법.** 브라우저 설정에서 사이트 데이터를 삭제하거나 저장을 차단하면 된다. 차단해도 서비스는 이용할 수 있으며, 다만 접속할 때마다 동의 화면이 다시 나온다.

## 15. 민감정보

이 서비스는 「개인정보 보호법」제23조의 **민감정보를 수집하지 않는다.** 건강, 성생활, 정치적 견해, 종교, 노동조합 가입 여부를 묻거나 별도로 뽑아내지 않는다.

다만 **대화 본문에 그런 내용이 섞여 있을 수 있다.** 대화는 이용자가 올리는 것이고 서비스는 그 안에서 민감정보만 골라낼 방법이 없다. 그래서 다음과 같이 다룬다.

1. 대화 내용 전체를 하나로 다루며 민감정보를 따로 분류하거나 저장하지 않는다.
2. 모든 대화는 4장의 보유 기간에 따라 **5분 뒤 파기**한다.
3. 업로드 화면에서 전화번호·주소·계좌번호·사진 등을 가리도록 안내한다.

> **검토 필요.** 이용자가 올린 대화에 민감정보가 포함된 경우 제23조의 별도 동의가 필요한지, 아니면 수집하지 않는 것으로 볼 수 있는지는 법률 검토가 필요하다.

## 16. 자동화된 결정

서비스는 인공지능 모델을 사용해 대화를 분석하고 지표를 산출한다. 이 과정에 사람의 개입은 없다.

「개인정보 보호법」제37조의2는 **정보주체의 권리 또는 의무에 중대한 영향을 미치는** 자동화된 결정에 대해 설명 요구권과 거부권을 정한다. 이 서비스의 결과는 **오락 목적의 추정**이며 채용·신용·계약 등 어떤 법적 효력도 갖지 않는다. 그래서 같은 조의 대상이 아니라고 본다.

그럼에도 아래를 밝힌다.

| | |
| --- | --- |
| 판단 기준 | 메시지 수, 답장 간격, 먼저 연락한 비율 등은 **코드가 계산**한다. 감정·노력·갈등의 정도만 인공지능 모델이 0~100으로 판단한다 |
| 처리 과정 | 캡처 → 문자 인식 → 화자·시각 복원 → 지표 계산 → 설명 글 작성 |
| 거부 방법 | 서비스를 이용하지 않으면 된다. 결과는 5분 뒤 사라지며 언제든 즉시 삭제를 요청할 수 있다 |

> **검토 필요.** 제37조의2의 적용 대상이 아니라는 판단은 "중대한 영향"의 해석에 달려 있다. 법률 검토가 필요하다.
