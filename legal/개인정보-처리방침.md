## 1. 처리하는 개인정보 항목

| 구분 | 항목 | 언제 |
| --- | --- | --- |
| 이용자가 올리는 것 | 메신저 대화 화면 캡처 이미지 | 분석 요청 시 |
| 캡처에서 뽑는 것 | 대화 텍스트, 발신 시각, 화자 구분 | 분석 중 |
| 자동으로 수집되는 것 | 접속 IP 주소 | 요청 시 |

**계정을 만들지 않는다.** 이름, 전화번호, 이메일, 로그인 정보를 받지 않는다.

**IP 주소는 저장하지 않는다.** 이용 횟수 제한을 위해 메모리에서만 세며, 하루가 지나거나 서버가 재시작되면 사라진다.

## 2. 처리 목적

1. 업로드한 대화의 관계 지표 산출과 결과 제공
2. 과도한 이용 방지(IP 기준 횟수 제한)
3. 오류 대응과 서비스 안정성 확인

**다른 목적으로 쓰지 않는다.** 광고, 프로파일링, 인공지능 모델 학습에 사용하지 않는다.

## 3. 대화 상대방의 개인정보

이 서비스의 가장 중요한 부분이므로 따로 적는다.

이용자가 올리는 캡처에는 **대화 상대방이 쓴 메시지**가 들어 있다. 상대방은 이 서비스에 동의한 적이 없다.

그래서 다음과 같이 처리한다.

1. **이용자는 본인이 참여한 대화만 올려야 한다.** 업로드 전에 이를 확인받는다.
2. 대화 내용은 **분석에만 쓰고 20분 뒤 삭제**한다. 이용자가 즉시 삭제를 요청할 수도 있다.
3. **대화 원문을 화면으로 되돌려 보내지 않는다.** 분석 결과에는 요약된 서술만 실린다. 원문 조각이 섞이지 않도록 서버가 한 번 더 검사해 걸러낸다.
4. **대화 원문을 기록에 남기지 않는다.** 운영 기록에는 메시지 개수, 이미지 장수 같은 숫자만 남는다.
5. 대화 상대방이 자신의 정보 처리를 확인하고 싶으면 {{연락처}}로 요청할 수 있다. 다만 계정과 식별자를 저장하지 않으므로, **20분이 지난 자료는 확인할 방법이 없다.**

> **검토 필요.** 이 구성은 "이용자가 정당한 권한으로 올린다"는 전제 위에 있다. 「개인정보 보호법」상 운영자의 지위, 상대방의 열람·삭제 요구권, 동의 없는 수집의 적법 근거는 법률 검토가 필요하다.

## 4. 보유 및 이용 기간

| 항목 | 기간 |
| --- | --- |
| 업로드 이미지 | 분석 시작 **20분** 뒤 자동 삭제 |
| 추출된 대화 텍스트 | 위와 같음 |
| 분석 결과 | 위와 같음 |
| IP 주소 | 저장하지 않음(메모리에서만 계수) |
| 운영 기록 | 대화 원문이나 식별자를 포함하지 않음 |

이용자가 결과 화면에서 삭제를 요청하면 **즉시 파기**한다. 파기한 자료는 복구할 수 없으며 백업을 두지 않는다.

## 5. 제3자 제공

분석 과정에서 아래 사업자에게 데이터가 전송된다.

| 받는 곳 | 소재 | 보내는 것 | 목적 | 학습 이용 | 보관 |
| --- | --- | --- | --- | --- | --- |
| Groq, Inc. | 미국 | **추출된 대화 텍스트** | 관계 분석·설명 글 작성 | 계약상 금지 | 하지 않음 |

**업로드한 이미지는 외부로 나가지 않는다.** 문자 인식은 서비스 서버 안에서 처리한다.

**모델을 만든 회사는 제3자가 아니다.** 사용하는 인공지능 모델은 공개된 가중치 파일이며 Groq이 자사 장비에서 실행한다. 모델 제작사는 이용자의 대화를 받지 않는다.

Groq은 계약상 입력과 출력을 학습이나 미세조정에 사용할 수 없으며, 운영자는 데이터 보관을 하지 않는 설정(Zero Data Retention)을 적용했다.

## 8. 정보주체의 권리

이용자와 대화 상대방은 자신의 개인정보에 대해 열람, 정정, 삭제, 처리 정지를 요구할 수 있다. {{연락처}}로 요청한다.

다만 이 서비스는 **계정과 식별자를 저장하지 않는다.** 그래서 특정인의 자료를 찾아낼 방법이 없고, **20분이 지나면 자료 자체가 남아 있지 않다.** 이용자는 결과 화면에서 언제든 즉시 삭제를 요청할 수 있다.

## 9. 파기 절차와 방법

1. 보유 기간이 지나거나 이용자가 요청하면 **지체 없이 파기**한다.
2. 자료는 메모리에만 두며 별도 저장 장치에 기록하지 않는다. 파기는 메모리에서 제거하는 방식으로 이루어진다.
3. **백업을 두지 않는다.** 파기한 자료는 복구할 수 없다.

## 10. 안전성 확보 조치

1. 전송 구간은 HTTPS로 암호화한다.
2. 대화 원문을 운영 기록에 남기지 않는다.
3. 분석 작업의 식별자를 기록에 남기지 않는다.
4. 자료는 저장 장치가 아니라 메모리에만 둔다.
5. 인공지능 사업자에게 데이터 미보관 설정을 적용한다.
6. 이용 횟수를 제한해 대량 수집을 막는다.

## 11. 만 14세 미만 아동

**만 14세 미만은 이용할 수 없다.** 업로드 전에 만 14세 이상임을 확인받으며, 법정대리인 동의 절차를 두지 않는다.
